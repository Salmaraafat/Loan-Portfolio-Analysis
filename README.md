# Loan Portfolio Analysis | Power BI

## 📌 Project Overview
An interactive Power BI dashboard analyzing 10,000 loan records to explore loan performance, customer activity, branch performance, and loan trends.

## 🎯 Objectives
- Analyze issued and refused loans.
- Compare loan performance across branches, governorates, and loan products.
- Identify common loan refusal reasons.
- Track monthly and yearly loan trends.

## 🛠️ Tools & Skills
- Power BI Desktop
- Data Modeling
- Data Visualization
- Data Analysis

## 📊 Key Insights
- **Total Loans:** 10,000
- **Issued Loans:** 8,520 (85.2%)
- **Refused Loans:** 1,480 (14.8%)
- **Total Branches:** 20

## 🧩 Data Model
Created relationships between five tables: `loans`, `customers`, `branches`, `installments`, and `transactions`.
